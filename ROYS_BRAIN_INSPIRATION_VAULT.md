## ✨ 5. Micro-Interactions, Color Palettes & Unique Layouts

### 💡 Design Snippet 1: The "Live Dispatch" Floating Badge
* **Code / Concept:**
  ```html
  <span class="inline-flex items-center gap-1.5 px-3 py-1 rounded-full text-xs font-bold bg-orange-500/10 text-orange-500 border border-orange-500/20">
    <span class="w-2 h-2 rounded-full bg-orange-500 animate-pulse"></span>
    Live Dispatch Available
  </span>
  ```
* **Why it works:** Creates ethical urgency without fake countdown timers.

### 💡 Design Snippet 2: 1-Click Voucher Copy Box
* **Code / Concept:** Dashed border container with monospace promo code (`font-mono`) + automatic clipboard copy + smooth scroll down to the booking form.
* **Why it works:** Gives the user an interactive feeling of claiming a physical coupon voucher.
